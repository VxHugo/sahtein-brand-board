# Sahtein Cozinha Árabe

Este projeto consiste no desenvolvimento de um brand board (guia visual) para um restaurante de culinária árabe.

## Contexto

O trabalho foi desenvolvido a partir de uma demanda real: o restaurante pertence à mãe de um amigo, e a proposta surgiu com a ideia de melhorar a identidade visual do negócio e preparar a marca para um ambiente digital mais profissional.

O objetivo não era apenas “deixar bonito”, mas criar uma base consistente que pudesse ser aplicada em diferentes pontos de contato, como site, redes sociais e materiais visuais.

## Objetivo do projeto

- Organizar uma identidade visual clara e coerente
- Definir uma paleta de cores funcional
- Estabelecer tipografia e estilo visual
- Criar uma base para o desenvolvimento do site
- Tornar a marca mais moderna e profissional

## Direção de design

A proposta visual foi construída com base em três pilares:

- Simplicidade: evitar excesso de elementos e manter o layout limpo
- Identidade cultural: referências sutis à estética árabe, sem sobrecarregar
- Funcionalidade: facilitar aplicação futura em interface e comunicação

A cor azul foi mantida como elemento principal da marca, por já fazer parte da identidade existente, sendo complementada por tons neutros para equilíbrio visual.

## Entregas

O projeto inclui:

- Brand board completo
- Paleta de cores com aplicação definida
- Definição tipográfica
- Estrutura visual base para interface
- Organização de elementos reutilizáveis

## Tecnologias utilizadas

- HTML
- CSS
## Observações

Este projeto foi desenvolvido como parte de estudo e portfólio, porém com base em um cenário real e aplicável.
